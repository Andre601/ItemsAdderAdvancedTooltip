# ItemsAdderAdvancedTooltip

ItemsAdderAdvancedTooltip is a simple client-side Fabric mod for 1.21.11 that is intended to be used when joining Servers running ItemsAdder.

The mod modifies the `minecraft:<id>` displayed on an Item's Hover when Advanced Tooltips is enabled, replacing it with the custom namespace and ID of the item, if it is a custom one added by ItemsAdder.  
This feature is only visual. The Item itself is unaffected from this.
